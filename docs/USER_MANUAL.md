# 사용자 매뉴얼

## 개요

ISMS 관리 시스템은 ISMS-P (정보보호 및 개인정보보호 관리체계) 인증 준비 및 유지를 위한 통합 관리 시스템입니다.

### 주요 기능

- **증적 관리**: 통제항목별 증적 등록, 버전 관리, 유효기간 관리
- **감사 지원**: 내부감사 계획, 체크리스트, 부적합 관리
- **사용자 관리**: 역할 기반 접근 제어, 부서 관리
- **대시보드**: 인증 준비 현황, 알림, 통계

---

## 시작하기

### 로그인

1. 시스템 URL 접속 (https://isms.your-domain.com)
2. 이메일과 비밀번호 입력
3. **로그인** 버튼 클릭

![로그인 화면](images/login.png)

### 2단계 인증 (MFA)

MFA가 활성화된 경우:

1. 로그인 후 OTP 입력 화면 표시
2. 인증기 앱(Google Authenticator 등)에서 6자리 코드 확인
3. 코드 입력 후 **확인** 버튼 클릭

### 비밀번호 정책

- 최소 8자 이상
- 대문자, 소문자, 숫자, 특수문자 포함
- 90일마다 변경 필요
- 이전 5개 비밀번호 재사용 불가

## 대시보드

대시보드는 로그인 후 첫 화면으로, 전체 현황을 한눈에 파악할 수 있습니다.

### 구성 요소

#### 1. 인증 준비 진척률

![진척률 게이지](images/dashboard_progress.png)

- **증적 확보율**: 등록된 증적 / 필요 증적 × 100%
- 색상: 녹색(80%↑), 노란색(50-80%), 빨간색(50%↓)

#### 2. 예정 활동

오늘/이번 주 예정된 보안 활동 목록

- 클릭 시 해당 활동 상세 페이지로 이동
- 마감일 임박 시 빨간색 표시

#### 3. 만료 예정 증적

30일 이내 만료 예정인 증적 목록

- 만료일 표시
- 클릭 시 증적 상세 페이지로 이동

#### 4. 미완료 업무

담당자에게 할당된 미완료 업무

- 업무 유형 (증적 업데이트, 시정조치 등)
- 기한 표시

#### 5. 부적합 현황

부적합 사항 통계

- 상태별 (미조치/조치중/완료)
- 유형별 (중결함/경결함)

## 증적 관리

### 증적 목록 조회

**메뉴**: 증적 관리 > 증적 목록

![증적 목록](images/evidence_list.png)

#### 필터 옵션

- **통제항목**: 특정 통제항목에 매핑된 증적
- **상태**: 활성/만료/보관
- **기간**: 유효기간 범위
- **담당자**: 업로드한 사용자

#### 정렬 옵션

- 제목, 등록일, 만료일, 버전

### 증적 등록

**메뉴**: 증적 관리 > 증적 등록

![증적 등록](images/evidence_create.png)

#### 등록 절차

1. **기본 정보 입력**
   - 제목 (필수)
   - 설명
   - 작성자

2. **파일 업로드**
   - 드래그 앤 드롭 또는 파일 선택
   - 지원 형식: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, JPG, PNG
   - 최대 크기: 100MB

3. **통제항목 매핑**
   - 관련 통제항목 선택 (다중 선택 가능)
   - 검색으로 통제항목 찾기

4. **유효기간 설정**
   - 시작일, 종료일 선택
   - 정기 활동 여부 체크
   - 정기 활동 주기 설정 (매월/분기/반기/연간)

5. **등록** 버튼 클릭

### 증적 상세 조회

![증적 상세](images/evidence_detail.png)

#### 주요 정보

- 기본 정보 (제목, 설명, 상태)
- 파일 정보 (파일명, 크기, 해시)
- 매핑된 통제항목
- 버전 히스토리
- 검토 정보

#### 가능한 작업

- **다운로드**: 파일 다운로드
- **수정**: 증적 정보 수정
- **새 버전 업로드**: 버전 업데이트
- **삭제**: 증적 삭제 (관리자만)

### 증적 버전 관리

![버전 히스토리](images/evidence_versions.png)

#### 새 버전 업로드

1. 증적 상세 페이지에서 **새 버전 업로드** 클릭
2. 새 파일 선택
3. 변경 사항 설명 입력
4. **업로드** 클릭

#### 이전 버전 조회

- 버전 히스토리에서 이전 버전 확인
- 각 버전의 파일 다운로드 가능

## 감사 관리

### 감사 계획 조회

**메뉴**: 감사 관리 > 감사 계획

![감사 계획 목록](images/audit_list.png)

#### 감사 유형

- **내부감사**: 조직 내부에서 수행
- **외부감사**: 외부 기관에서 수행
- **인증심사**: ISMS-P 인증 심사

### 감사 계획 생성

![감사 계획 생성](images/audit_create.png)

#### 입력 항목

1. **기본 정보**
   - 감사 제목
   - 감사 유형 선택
   - 감사 설명

2. **일정**
   - 시작일, 종료일

3. **범위**
   - 감사 범위 설명
   - 대상 통제영역 선택

4. **감사팀**
   - 수감사인 선택
   - 팀 구성원 추가

### 체크리스트 관리

![체크리스트](images/audit_checklist.png)

#### 체크리스트 작성

1. 감사 상세 페이지에서 **체크리스트** 탭 선택
2. 각 항목에 대해:
   - 결과 선택 (적합/부적합/관찰사항/해당없음)
   - 발견사항 기록
   - 증적 참조 추가

#### 결과 값

| 결과 | 설명 |
|------|------|
| 적합 | 요구사항 충족 |
| 부적합 | 요구사항 미충족 (시정조치 필요) |
| 관찰사항 | 개선 권고사항 |
| 해당없음 | 조직에 해당되지 않음 |

### 부적합 관리

**메뉴**: 감사 관리 > 부적합

![부적합 목록](images/nonconformity_list.png)

#### 부적합 유형

- **중결함 (Major)**: 즉각적인 시정조치 필요
- **경결함 (Minor)**: 개선 필요

#### 부적합 상태

| 상태 | 설명 |
|------|------|
| 미조치 | 시정조치 미시작 |
| 조치중 | 시정조치 진행 중 |
| 조치완료 | 시정조치 완료, 검증 대기 |
| 종결 | 검증 완료 |
| 기한초과 | 기한 내 미완료 |

#### 시정조치 등록

1. 부적합 상세 페이지에서 **시정조치 추가** 클릭
2. 조치 내용 입력
3. 조치 증적 첨부
4. **등록** 클릭

## 자주 묻는 질문 (FAQ)

### 로그인 관련

**Q: 비밀번호를 잊어버렸습니다.**
A: 관리자에게 비밀번호 초기화를 요청하세요.

**Q: 계정이 잠겼습니다.**
A: 30분 후 자동 해제되거나, 관리자에게 해제를 요청하세요.

**Q: MFA 인증기를 분실했습니다.**
A: 관리자에게 MFA 초기화를 요청하세요.

### 증적 관련

**Q: 파일 업로드가 안 됩니다.**
A: 파일 크기(100MB 이하), 형식을 확인하세요.

**Q: 증적을 삭제하고 싶습니다.**
A: 관리자 권한이 필요합니다. 관리자에게 요청하세요.

**Q: 이전 버전 파일을 복원하고 싶습니다.**
A: 버전 히스토리에서 이전 버전을 다운로드한 후 새 버전으로 업로드하세요.

### 알림 관련

**Q: 알림이 오지 않습니다.**
A: 설정 > 알림에서 알림이 활성화되어 있는지 확인하세요.

**Q: 이메일 알림을 끄고 싶습니다.**
A: 설정 > 알림에서 이메일 알림을 비활성화하세요.
